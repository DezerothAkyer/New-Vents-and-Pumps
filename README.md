# New-Vents-and-Pumps

Modifies and adds new vents and pumps to Ostranauts. Probably alarms as a bonus, as well.

 - Update .02: Now features temperature pumps in both Turbo and regular flavor. Made them into their own separate pumps, with unique corporations and names. They can switch between pumping when the thermostat reads hot or cold. HOWEVER, they can only be programmed to while the thermostat reads the temperature they're searching for. So if you have a cold pump, you need to get the room cold before you link it to the thermostat, for instance. It's a quirk of Guipropmaps, haven't found a way around it.
 - Next up should be some sort of store to buy the new merchandise.

Thus far, adds:
 - A configurable auto vent, with three different modes at 15, 10, and 5 KpA
 - Pumps configured to work off of thermostats instead of pressure sensors

Be warned that at this early stage, the jsons are VERY undercooked. There's a lot of redundant data in there that I think I'll be using but am not 100% sure on. It's ugly, basically. There will be bloat, although there shouldn't be any significant performance impacts.
